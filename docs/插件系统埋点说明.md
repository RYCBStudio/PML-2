# PML 2 插件系统埋点说明

本文档介绍 PML 2（MEFrpLauncherX）插件系统的全部埋点，分为三类：

1. **插件事件触发点（Trigger）** —— 程序在关键时机触发，供插件 YAML 订阅
2. **日志埋点** —— 插件系统内部通过 `LogUtil` 写入的日志
3. **分析埋点（Sentry）** —— 通过 `AppAnalytics` 上报的匿名统计

---

## 一、插件事件触发点（Trigger）

插件通过 YAML 中的 `triggers.on` 订阅以下事件。事件携带的数据可通过模板
`{{ctx.data.字段名}}` 在动作参数中引用。

### 事件总览

| 事件名 | 触发时机 | 触发位置 | 携带数据 | 执行方式 |
| --- | --- | --- | --- | --- |
| `app.startup` | 主窗口初始化完成、应用启动时 | `MainWindow.axaml.cs` | `version`, `os` | await |
| `app.exit` | 应用退出时（日志释放前） | `App.axaml.cs` | `version`, `os` | await |
| `app.update.available` | 检测到有新版本时 | `MainWindow.axaml.cs` | `currentVersion`, `latestVersion` | fire-and-forget |
| `user.login` | 用户登录成功时 | `LoginPage.axaml.cs` | `username`, `group` | fire-and-forget |
| `user.logout` | 用户确认登出后、应用重启前 | `UserCenterPage.axaml.cs` | `username` | await |
| `proxy.start` | 启动隧道（创建带 mefrpc 命令的终端标签页）时 | `TerminalPage.axaml.cs` | `proxyName`, `command` | fire-and-forget |
| `proxy.stop` | 关闭终端标签页（与 `proxy.start` 配对）时 | `TerminalPage.axaml.cs` | `proxyName` | fire-and-forget |
| `page.navigate` | 切换主界面页面时 | `MainPageFrameViewModel.cs` | `page` | fire-and-forget |
| `plugin.install` | 插件文件安装成功时 | `PluginService.cs` | `file` | fire-and-forget |
| `plugin.uninstall` | 插件卸载成功时 | `PluginService.cs` | `pluginId`, `pluginName` | fire-and-forget |
| `plugin.enable` | 插件启用时 | `PluginService.cs` | `pluginId` | fire-and-forget |
| `plugin.disable` | 插件禁用时 | `PluginService.cs` | `pluginId` | fire-and-forget |

### 事件详情

#### app.startup / app.exit

应用生命周期事件。`app.startup` 在主窗口加载、隐私政策检查完成后触发；
`app.exit` 在进程退出前触发，会等待插件动作执行完毕才释放日志资源。

| 数据字段 | 说明 | 示例 |
| --- | --- | --- |
| `version` | 应用版本号 | `26.2.0` |
| `os` | 操作系统平台 | `Win32NT` / `Unix` |

#### app.update.available

启动后首次检查到新版本时触发（每次运行只触发一次）。

| 数据字段 | 说明 |
| --- | --- |
| `currentVersion` | 当前版本 |
| `latestVersion` | 检测到的最新版本 |

#### user.login / user.logout

| 数据字段 | 说明 |
| --- | --- |
| `username` | 登录/登出的用户名 |
| `group` | 用户组（仅 `user.login`） |

> `user.logout` 之后应用会立即重启，因此采用 await 方式执行，
> 保证插件动作（如通知、上报）能完整执行。

#### proxy.start / proxy.stop

| 数据字段 | 说明 |
| --- | --- |
| `proxyName` | 隧道/终端标签页名称 |
| `command` | 启动命令（仅 `proxy.start`） |

#### page.navigate

`page` 字段取值：
`Home`、`CreateProxy`、`ManageProxy`、`NodesMonitoring`、`UserCenter`、
`Settings`、`About`、`Terminal`、`Update`、`Theme`、`Plugin`

#### plugin.install / plugin.uninstall / plugin.enable / plugin.disable

插件自身管理事件。注意：插件可以订阅这些事件实现联动，
但订阅 `plugin.uninstall` 的插件在自身被卸载后不会再收到后续事件。

## 二、插件 YAML 写法

插件文件位于 `Config/Plugins/*.yaml`，支持热重载（文件变更后 1 秒内自动重载）。

```yaml
id: my-plugin
name: 示例插件
description: 隧道启动时发送通知
author: 作者名
version: "1.0"

triggers:
  - on: proxy.start                          # 订阅的事件名
    condition: "ctx.data.proxyName != ''"    # 可选，条件表达式
    actions:
      - name: notify
        params:
          msg: "隧道 {{ctx.data.proxyName}} 已启动"

functions:
  my_func:                                   # 可复用函数，用 call_function 调用
    - name: log
      params:
        msg: "hello"
```

### 内置指令（actions）

| 指令 | 参数 | 说明 |
| --- | --- | --- |
| `log` | `msg` | 写日志（控制台 + 应用日志文件，模块为"插件"） |
| `notify` | `msg` | 发送系统通知（标题为 `插件ID \| PML 2`） |
| `http_request` | `url`, `method`(默认 GET), `body` | 发 HTTP 请求，响应体写入 `ctx.variables.http_response` |
| `python_run` | `script`, `input` | 调用 Python 脚本（需 PATH 中有 `python3`），返回的 JSON 合并进变量 |
| `call_function` | `func`, `args` | 调用 `functions` 中定义的函数 |
| `conditional` | `condition`, `if_true` | 条件执行一组动作 |

### 模板变量

参数中的 `{{...}}` 会在执行前替换：

- `{{ctx.data.xxx}}` —— 事件携带的数据
- `{{ctx.variables.xxx}}` —— 执行过程中产生的变量（如 `http_response`）

## 三、日志埋点（LogUtil）

插件系统相关日志统一使用 `EnumLogModule.Plugin`（模块名"插件"），
写入 `Logs/yyyy-MM-dd.log`。

### PluginService（`MEFrpLauncherX.Plugin/Services/PluginService.cs`）

| 时机 | 级别 | 内容 |
| --- | --- | --- |
| 插件加载完成 | Info | 插件总数、启用数、禁用数、耗时(ms) |
| 插件加载失败 | Error | 异常详情 |
| 重新加载 | Info | 提示正在重载 |
| 启用 / 禁用插件 | Info | 插件 ID |
| 事件执行完成 | Debug | 事件名、耗时(ms) |
| 事件执行失败 | Error | 事件名、异常详情 |
| 安装 / 卸载插件成功 | Info | 文件名 / 插件名 |
| 安装 / 卸载插件失败 | Error | 异常详情 |
| 解析插件元数据失败 | Warning | 文件路径、错误信息 |
| 保存 / 读取禁用列表失败 | Error / Warning | 错误信息 |

### PluginEngine（`MEFrpLauncherX.Plugin/Engine/PluginEngine.cs`）

| 时机 | 级别 | 内容 |
| --- | --- | --- |
| 加载完成汇总 | Info | 成功数、失败数、监听事件种类数、注册函数数 |
| 单个插件文件加载失败 | Warning | 文件路径、错误信息 |
| 事件无订阅插件 / 命中插件数 | Debug | 事件名、命中数 |
| 条件解析或求值失败 | Warning | 插件 ID、条件表达式 |
| 条件不满足跳过 | Debug | 插件 ID、事件名 |
| 动作开始执行 | Debug | 插件 ID、事件名、动作数 |
| 未知指令 | Warning | 指令名、插件 ID |
| 指令执行失败 | Error | 指令名、插件 ID、异常详情 |

### PluginPreprocessor（`MEFrpLauncherX.Plugin/Engine/PluginPreprocessor.cs`）

| 时机 | 级别 | 内容 |
| --- | --- | --- |
| 插件文件不存在 / 读取失败 / 读取异常 | Warning | 文件路径、错误信息 |
| `#include` 引用的文件不存在 | Warning | 主文件与 include 路径 |
| YAML 反序列化失败 | Warning | 文件路径、错误信息 |

### BuiltInActions（`MEFrpLauncherX.Plugin/Core/BuiltInActions.cs`）

| 指令 | 时机 | 级别 | 内容 |
| --- | --- | --- | --- |
| `log` | 每次执行 | Info | 插件 ID + 消息 |
| `http_request` | 请求完成 | Debug | 方法、URL、状态码、耗时(ms) |
| `http_request` | 非 2xx 状态 | Warning | 状态码、URL |
| `http_request` | 请求异常 | Warning | 方法、URL、错误信息 |
| `python_run` | 执行完成 | Debug | 耗时(ms) |
| `python_run` | 退出码非 0 | Warning | 退出码、耗时、stderr |
| `python_run` | 执行失败 | Warning | 错误信息 |
| `call_function` | 找不到函数 | Warning | 插件 ID、函数名 |

### HotReloadService（`MEFrpLauncherX.Plugin/Engine/HotReloadWatcher.cs`）

| 时机 | 级别 | 内容 |
| --- | --- | --- |
| 监听启动 / 停止 | Debug | 监听目录 |
| 检测到插件文件变更（1 秒防抖） | Info | 变更类型、文件名 |
| 热重载失败 | Error | 异常详情 |

## 四、分析埋点（Sentry / AppAnalytics）

分析功能由 `AppAnalytics`（`MEFrpLauncherX.Core/Analysis/AppAnalysis.cs`）封装，
基于 Sentry。**仅在用户同意隐私政策（`IsTelemetryEnabled`）后才会上报**，
所有调用在未启用时自动跳过。

### 可用 API

| API | 用途 |
| --- | --- |
| `TrackAction(name, data)` | 记录用户/系统行为（Breadcrumb） |
| `TrackPage(pageName)` | 记录页面浏览 |
| `TrackCost(name, action)` / `TrackCostAsync` / `TrackCostWithTimerAsync` | 记录操作耗时（Transaction），异常自动上报 |
| `CaptureException(ex, tag)` | 上报异常，可附加 `op` 标签 |
| `SetUserId(id, username, email)` | 关联用户身份 |

### 插件系统相关埋点

#### PluginService

| 埋点名 | 类型 | 时机 | 附加数据 |
| --- | --- | --- | --- |
| `plugin.load` | TrackAction | 插件加载完成 | `count`, `enabled`, `costMs` |
| `plugin.load` | CaptureException | 加载失败 | — |
| `plugin.reload` | TrackAction | 重新加载 | — |
| `plugin.enable` / `plugin.disable` | TrackAction | 启用 / 禁用 | `pluginId` |
| `plugin.install` / `plugin.uninstall` | TrackAction | 安装 / 卸载成功 | `file` / `pluginId` |
| `plugin.install` / `plugin.uninstall` | CaptureException | 失败 | — |
| `plugin.trigger:{事件名}` | CaptureException | 事件执行失败 | — |
| `plugin.parse-meta` | CaptureException | 元数据解析失败 | — |

#### PluginListViewModel（插件市场 UI）

| 埋点名 | 类型 | 时机 | 附加数据 |
| --- | --- | --- | --- |
| `plugin.market.refresh` | TrackAction / CaptureException | 刷新在线插件列表 成功/失败 | `count` |
| `plugin.market.download` | TrackAction / CaptureException | 下载安装在线插件 成功/失败 | `selected`, `installed` |
| `plugin.install.local` | TrackAction / CaptureException | 文件选择器本地安装 成功/失败 | `selected`, `installed` |
| `plugin.install.drop` | TrackAction | 拖放安装 | `installed` |
| `plugin.list.reload` | TrackAction | 列表手动刷新 | — |
| `plugin.uninstall.ui` | CaptureException | UI 卸载失败 | — |

### 其他模块埋点（参考）

| 埋点名 | 位置 | 说明 |
| --- | --- | --- |
| `api.icp.domain-list`、`api.system.status`、`api.user-info`、`api.nodes.status`、`api.nodes.info`、`api.nodes.name-list`、`api.proxy.list`、`api.proxy.token` | `MEFApiConverter` | API 调用耗时事务（TrackCostAsync） |
| `SetUserId` | `LoginPage`、`HomePageViewModel` | 登录/自动登录后关联用户 |

## 五、新增埋点指南

### 新增一个插件 Trigger

1. 在合适的业务时机处调用：

   ```csharp
   using MEFrpLauncherX.Plugin.Services;

   // 不阻塞当前流程
   _ = PluginService.Instance.TriggerAsync("my.event", new Dictionary<string, object>
   {
       ["key"] = value
   });

   // 或需要等待插件执行完毕再继续（如进程即将退出）
   await PluginService.Instance.TriggerAsync("my.event", data);
   ```

2. 事件名约定：小写 + 点分层级，如 `域.动作`（`proxy.start`、`app.update.available`）。
3. `TriggerAsync` 内部已包含异常捕获，插件报错不会影响主流程，无需额外 try/catch。

### 新增日志埋点

```csharp
App.CurrentLogger.Log("消息", module: EnumLogModule.Plugin);        // Info
App.CurrentLogger.Warning("消息", module: EnumLogModule.Plugin);    // Warning
App.CurrentLogger.Error(ex, "消息", module: EnumLogModule.Plugin);  // Error
App.CurrentLogger.LogDebug("消息", module: EnumLogModule.Plugin);   // 仅 Debug 构建
```

### 新增分析埋点

```csharp
AppAnalytics.TrackAction("my.action", new Dictionary<string, string>
{
    ["key"] = value
});
AppAnalytics.CaptureException(ex, "my.operation");
```

> 注意：分析数据仅在用户同意隐私政策后上报，请勿在埋点数据中包含敏感信息。
