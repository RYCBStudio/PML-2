## 26.3 里程碑落点

- **M1 节点延迟/连通性**（落点：隧道管理页）：`UserProxyViewModel`（探测属性/方法）、`ManageProxyViewModel`（`ProbeAllCommand`）、`UserProxyControl.axaml`（延迟展示）、`ManageProxyPage.axaml`（刷新测速按钮）、`Core/Services/NodeProbeService.cs`（TCP Connect，超时 4s，并发 6）。
- **M2 创建隧道预填与模板**（落点：创建页）：`CreateProxy.axaml(.cs)`（`127.0.0.1` 预填/端口快捷 80/443/22/25565/模板 UI）、`ConfigManager`（`ProxyTemplates` 持久化）、`Models/ProxyTemplate.cs`（已登记 AOT）。
- **M3 隧道状态与失败原因**（落点：隧道管理页 + 终端）：`UserProxyViewModel`（`TunnelStatus` 状态机/`LastErrorSummary`）、`TerminalPage.CreateNewTerminalWithoutNotification`（输出回调）、`Core/Services/TunnelErrorMapper.cs`（认证失败/端口占用/节点不可达/进程崩溃）、`TunnelErrorPresenter`。
- **M4 更新页与失败路径**（落点：更新页）：`UpdatePageViewModel`（`DownloadUpdate` 安全化、`HasDownloadFailed`/`FailureTip`/`RetryDownloadCommand`、`BuildUpdateDownloadUrl` 抽取）、`UpdatePage.axaml`（重试下载按钮）。
- **M5 macOS 原生菜单**（落点：主窗口）：`MainWindow.axaml.cs` `NativeMenuBar` 段，命令与主界面同源（`AppShellCommands` / `NavigateToPage`）。
- **M6 系统托盘**（落点：主窗口）：`MainWindow.axaml.cs` `CreateContextMenu` 增加「全部停止隧道」，其余项走 `AppShellCommands`。
- **M6b 流量悬浮窗**（落点：ProxyMonitor）：`ProxyFloatViewModel`（`RefreshTrafficCommand`）、`ProxyFloat.axaml`（MenuFlyout 三项绑定）、`App.axaml.cs`（`desktop.Exit` 时 `ProxyFloat.Instance?.Close()` 无残留）。
- **M7 开机自启与恢复隧道**（落点：设置页 + 主窗口）：`SettingsPage.axaml.cs`（Win 注册表 / Linux .desktop / macOS LaunchAgent）、`MainWindow.axaml.cs` AUTO_START 段（失败写日志 + Growl 提示）。
