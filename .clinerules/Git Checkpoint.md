# Git Checkpoint Rule
This rule is used to check the git checkpoint.

## When to use
Use if you have finished the tasks you have been assigned to and are fully checked CI-safeness and UX-friendliness.

## How to use
Once you've met the above conditions, commit your edits to Git.
The commit msg doesn't have a template, but the general standard is that you **MUST** Write clearly what you have done.
